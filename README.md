# Poddock — Release-Artefakte

Dieses Repository enthält **ausschließlich Binär-Artefakte** der Poddock-Releases (Daten-Tarball, x86_64- und aarch64-Binaries) als öffentlich erreichbare Quelle für die Flathub-Einreichung. Es enthält **keinen Quellcode**; der Quellcode bleibt privat.

Die Dateien werden automatisch vom Release-Workflow des privaten Haupt-Repositories hochgeladen.
